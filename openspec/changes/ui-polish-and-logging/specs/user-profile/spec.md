## MODIFIED Requirements

### Requirement: Profile Layout Redesign
The system SHALL present the User Profile view in a premium, mobile-first design, moving away from desktop-focused data tables to vertical card feeds for purchase history and user stats. The top navigation SHALL be converted into a mobile-friendly navbar, and the Inventory icon SHALL be updated to a modern vector graphic.

#### Scenario: User views their profile
- **WHEN** a user navigates to the Profile page on a mobile device
- **THEN** their purchase history is displayed as spaced cards, and they interact with a sleek top navbar incorporating an updated inventory icon.
